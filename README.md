# Геворк Бильярдинский — Android TV

Игра для двух человек на одном телевизоре TCL / Android TV. Полностью офлайн. Русский бильярд с упрощёнными правилами «свободной пирамиды»: любой оставшийся белый шар может быть выбран в качестве бьющего, каждый забитый шар приносит очко, успешный удар даёт дополнительный ход.

## Как играть
- ↑/↓ — выбрать белый шар, который будет бьющим.
- ←/→ — изменить направление удара (удержание ускоряет поворот).
- Зажать OK — набрать силу; отпустить OK — ударить.
- Назад — моментальная пауза (ещё раз Назад — продолжить).
- На прицеливание — 60 секунд; во время движения шаров таймер не расходуется.
- Одна партия до забивания всех 16 шаров, без общего ограничения по времени. Счёт игроков всегда сверху.
- Если шар забит — тот же игрок продолжает. Если нет — ход переходит сопернику.
- Фоновая музыка удалена; остались ненавязчивые игровые звуки с выключателем.
- После промаха — «АЙ ОХРАШ!», после забитого шара — «ХАЛАЛА АХПЕР ДЖАН!».
- Сила удара растёт линейно по времени удержания OK и достигает максимума примерно за 1,25 секунды; больше нет колебания мощности.

## Обновление 1.1 для TCL Android TV

Увеличена мощность удара, изменено трение и упругость борта, увеличена шкала силы, улучшены всплывающие надписи. Точный размер экрана 75 дюймов не требует отдельной сборки: интерфейс адаптируется к разрешению и пропорциям 16:9. Физика остаётся аркадной. Проект не тестировался на физическом пульте TCL.

## Сборка APK

Требуются: Android Studio с Android SDK Platform 35, JDK 17. Откройте эту папку как Android/Gradle проект в Android Studio, дождитесь установки Android Gradle Plugin 8.6.1 и нажмите Build → Build Bundle(s) / APK(s) → Build APK(s). Готовый файл появится в `app/build/outputs/apk/debug/app-debug.apk`. Для сборки из терминала при установленном Gradle: `gradle assembleDebug`.

## Запуск на TCL

Перенесите `app-debug.apk` на Android TV через флешку, локальную сеть или ADB. На ТВ разрешите установку из неизвестных источников для используемого файлового менеджера и установите APK. Проект поддерживает Android 6.0+ (API 23+) и Android TV Leanback Launcher. Не требуется интернет.

## Проверка без APK

`app/src/main/assets/index.html` открывается в Chrome, Edge или другом современном браузере. Положите рядом `dad.jpg`, нажмите «Играть вдвоём», управляйте стрелками и Enter. Можно открыть локальный файл напрямую — сети не требуется.

## Замечания

Физика 2D аркадная, а не сертифицированный спортивный симулятор. Кнопки Android TV могут отличаться по модели пульта. Выполняйте финальный тест удержания/отпускания OK и кнопки Back непосредственно на TCL.
