ОНЛАЙН-СБОРКА APK — без Android Studio
======================================
1. Создайте аккаунт на https://github.com и новый PRIVATE репозиторий (например, gevork-billiardinsky).
2. Распакуйте этот архив на компьютер.
3. На странице пустого репозитория выберите "uploading an existing file" / Add file → Upload files.
4. Перетащите содержимое распакованной папки (папки app, .github, файлы build.gradle, settings.gradle, gradle.properties и README.md) в GitHub. ВАЖНО: файлы должны быть в корне репозитория, не во вложенной папке.
   Проверьте, что скрытая папка .github тоже загрузилась; иначе используйте веб-редактор GitHub: Add file → Create new file, имя .github/workflows/build-apk.yml, вставьте текст из архива.
5. Нажмите Commit changes.
6. Откройте вкладку Actions → Build Android TV APK. Первая сборка запускается автоматически после загрузки (push), если ветка main/master. Если нет: Run workflow.
7. Дождитесь зелёной галочки и скачайте APK из раздела Artifacts на странице запуска workflow. В ZIP-артефакте будет app-debug.apk — это НАСТОЯЩИЙ устанавливаемый APK (подписанный отладочным ключом).
8. Передайте APK на телевизор и установите его с разрешением на установку из неизвестных источников.

Внимание: репозиторий PRIVATE, потому что проект содержит личное фото. Сборка через интернет требует доступ GitHub к коду. В ZIP нет заранее собранного APK. Для использования GitHub Actions на частном репозитории действует бесплатная квота GitHub и могут потребоваться настройки Actions.
